## 📥 How to Download

### **Option 1 — Direct Download (GitHub)**

1. Click any `.bsp` file in the `maps/` folder.
2. Press the **“Download”** button.

### **Option 2 — Through GameSession App**

1. Open the [GameSession Platform](https://gamesession.gg).
2. Choose a **Team Fortress 2** server featuring community maps.
3. Click the **download icon** in the game interface.
4. Follow the automatic installation steps.

---

## 🛠️ Installation Instructions

1. **Download** the desired `.bsp` map file.
2. **Locate** your TF2 installation directory:

   ```
   Steam Library → Team Fortress 2 → ⚙️ (Settings) → Properties → Installed Files → Browse
   ```
3. Navigate to:

   ```
   \Team Fortress 2\tf\maps\
   ```
4. **Copy** the `.bsp` file into that folder.
5. **Restart** Team Fortress 2 to load the new map.
